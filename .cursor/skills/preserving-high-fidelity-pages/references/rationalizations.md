# 高保真还原：借口对照表

有视觉源却想跳过对照时，用下表拦住。

| 借口 | 实际情况 |
|------|----------|
| 「代码更干净，视觉后面再调」 | 视觉是本任务的完成条件，不是收尾 |
| 「Element 默认就挺接近」 | 接近不算过；展开态、边框、字号都要对基线 |
| 「frontend-design 会更好看」 | 有视觉源时禁止再设计 |
| 「默认态已经一样了」 | hover / 下拉 / 空态 / 全屏没拍就没完成 |
| 「内部重构所以 CSS 对不上」 | 允许重构，但截图必须对上 |
| 「内网打不开，先凭印象做」 | 没有基线就没有高保真，先要源 |
